Práctica: Git y GitHub – Aplicación autónoma del flujo de trabajo

Objetivo y descripción:
Aplicar de manera autónoma el flujo de preparación, versionamiento y colaboración de un proyecto  utilizando Visual Studio Code, Python, Git y GitHub. En esta práctica no se proporcionan los comandos: cada instrucción describe una acción y el resultado esperado, y deberás determinar qué comando utilizar, ejecutarlo y comprobar su resultado.

Estructura general y tecnologías utilizadas:
Catalogo de recursos con varias carpetas y archivos en cada una utilizando tecnolgías como VS code, git y git hub 

Instrucciones para preparar el archivo y dependencias :
Abrir una nueva ventana en vs code y empezar con la terminal posicionandote en el lugar donde quieres crear el proyecto, empezar creando la carpeta rauz para posteriormente abrirla desde el explorador de archivos y comenzar con la creación de las carpetas y los archivos correspondientes, despues creamos el entorno virtual  con el comando "python .m venv .venv" lo activamos y nos salimos de esas carpetas hasta estar de nuevo en la raíz del proyecto 
veridficamos la versión de python y de pip para verificar que no exista ningun error, si es así empezamos instalando las bibliotecas a uitilizar en el proyecto utilizando el comando "pip install (nombre de la librería)", checamos si se han instalado correctamente con un pip list y genermaos el requirements con el comando "pip freeze > requirements.txt".
